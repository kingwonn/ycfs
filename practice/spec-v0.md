# UMI 数采设备规格书 v0

> 客户:具身大脑厂商(训 VLA / 基座模型)。目标(P13):最好、最适配、成本最优。
> 本文是"言→法"的第一张卡:把产品意图翻成**每项带机器可查验收**的规格。
> 规格写不出验收命令的,不算规格,是愿望——一律不收。
> 引用纪律:[有据]=公开来源;[推断]=待真人验证的设计假设。
>
> **地图声明**:本规格是设计草案,不是已验证的产品。全文最重的未决点在 §7(三条证伪条件)。

---

## 0. 设计立场:三个"最"如何排序

冲突时的优先级(不可同时最大化):

1. **最适配 > 最好 > 成本最优**。理由:数据买不进训练管线 = 零价值(格式否决先于质量)。
   一批高保真但格式对不上的数据,客户工程师连读都读不进,精度再高也是废的。
2. 但**成本最优是准入线**:单价必须落在遥操数据 $118/h 的成本曲线以下才有人谈 [有据]。

## 1. 采集与时间同步(否决级)

| # | 规格 | 机器可查验收 | 出处 |
|---|---|---|---|
| 1.1 | 各模态时间戳统一时钟,跨模态对齐误差 P99 ≤ 5ms(v0 目标,后续棘轮收紧) | 回放任一 episode,计算相机帧/位姿/夹爪三路时间戳两两最大偏差,P99 输出 ≤ 5ms 即过 | π0 要求亚毫秒硬同步 [有据];v0 先立可达门槛,不谎称亚毫秒 |
| 1.2 | 丢帧/掉线显式标记,禁止静默插值 | 扫描数据流,任何时间间隔 > 名义周期 1.5× 处必须有 `dropped:true` 标记;发现插值填充的连续段(方差异常低)判红 | 静默插值=编造数据,违反"零编造" |
| 1.3 | 位姿采样率 ≥ 30Hz,并记录原始时间戳(不重采样存原始) | 统计位姿流平均频率 ≥ 30Hz;原始时间戳字段非空 | LeRobot 主流 30fps [有据];原始率保留给下游自由重采样 |

> **诚实**:1.1 的 5ms 不是 π0 要的亚毫秒。这是消费级相机方案的真实上限。
> 含义写进 §7 证伪条件①——它决定我们能不能卖给 π0 系客户。

## 3. 动作标签 —— 直面证伪条件①(否决级)

| # | 规格 | 验收 | 出处/理由 |
|---|---|---|---|
| 3.1 | 主输出 = 末端位姿(EE pose)6-DoF + 夹爪开合,非关节角 | 每帧含 `ee_pose`(7维)+ `gripper`(1维) | UMI 无本体,给不了 joint state [有据] |
| 3.2 | **随设备附开源重定向层**(EE→目标本体关节的映射工具),输入客户 URDF 输出可行性报告 | 给定一个测试 URDF,重定向层跑通并输出每条轨迹的 IK 可行/不可行标注 | 对策:把 32.5% IK 废弃 [有据] 前移到交付前暴露,而非客户训练后才发现 |
| 3.3 | 交付即标注每条轨迹对"参考本体"的可行率 | `feasibility_rate` 字段存在且 ∈ [0,1] | 这是"最好"的可量化抓手之一 |

> **决策(非骑墙)**:v0 走 EE-pose 路线,不假装能出 joint-state。目标客户因此**收窄为
> 接受 EE-pose 输入或愿用重定向层的架构**;严格 joint-state 直训的 π0 系客户是 v0 的
> 非目标客户。这个收窄是清醒的取舍,不是遗漏。

## 4. 力 / 触觉 —— 直面证伪条件②(决策:不上,预留)

**v0 结论:主体不含力/触觉传感;架构预留标准接口(机械+数据 schema),留作 v1 差异化模块。**

依据:
- 第一性上,力/触觉是仿真结构盲区,是 UMI 相对仿真唯一不可替代的方向 [有据][前几轮推导]
- **但** π0/GR00T 公开输入均无力/触觉 [有据] → 今天是否有生产级买家**未验证(#1)**
- 在买家未验证前默认上力/触觉 = 超前投资,推高 BOM、拖慢 v0、赌一个没锚的未来
- 故 v0 保守:不上,但预留接口,使 v1 加装无需重构(参考 TacUMI 指尖 ViTac + 可锁定夹爪机构、UMI-FT 每指 F/T 的成熟路线 [有据])

| # | 规格 | 验收 |
|---|---|---|
| 4.1 | 指尖预留视触觉传感器安装位与数据通道(不装,留位) | 机械图含安装基准面;数据 schema 含 `tactile` 可选字段且 v0 恒为 null | 
| 4.2 | 夹爪机构支持后续加装可锁定结构(消除握力污染) | 机构设计评审:锁定改造不需重开主体模具 |

> **证伪条件②一旦被真人证实"今天就有买家",本决策立即翻案:力/触觉从预留升为 v1 主线。**

## 6. 保真度内建 —— "最好"的落地(质检随设备,不做第三方标准)

设备在采集时实时计算并随数据交付一张**质量证书**(十项,全部机器可算)。这是 P13
"质检内建进设备"的兑现,也是相对鹿明的差异化轴(§7③)。

| # | 指标 | 验收(证书字段 + 判据) |
|---|---|---|
| 6.1 | 时间对齐误差 | `sync_error_p99_ms` ≤ 阈值 |
| 6.2 | 位姿漂移 | `drift_mm_per_episode`,回环闭合计算 |
| 6.3 | 抖动 tremble | `tremble_score`,实测vs平滑轨迹偏差 |
| 6.4 | 完整性 | `missing_frame_rate` / `missing_cam_rate` |
| 6.5 | 有效性 | `abnormal_duration_rate` / `static_ratio` |
| 6.6 | 一致性 | 同任务轨迹聚类紧致度 |
| 6.7 | 多样性 | 场景/物体/技能计数 + 熵 |
| 6.8 | 可行率 | §3.3 的 `feasibility_rate` |
| 6.9 | 格式合规 | LeRobot schema 校验 pass |
| 6.10 | 溯源 | 每 episode:设备ID/时间/标定状态/采集者 |

> 证书本身遵守 YCFS 铁律:阈值只紧不松;质检器与被采数据分离;字段可被客户独立复算
> (我们给公式,不给"相信我们")。**卖家自评的质量客户能自己验 = 不是自证。**

## 7. 三条证伪条件的正面回应(本规格的承重墙)

| 证伪条件 | v0 的应对 | 未消除的风险 | 判定动作 |
|---|---|---|---|
| ① 50Hz/亚毫秒鸿沟 | §1 立 5ms 可达门槛 + §3 EE-pose + 重定向层 | π0 系严格 joint-state 客户仍够不着 | 领土问答②"卡格式还是卡质量"裁决优先级 |
| ② 力/触觉有无买家 | §4 不上、预留、可翻案 | 若买家已存在,v0 主动放弃了最强差异化 | 领土问答①"生产模型今天吃不吃力数据"直接裁决 |
| ③ 相对鹿明的量化优势 | 差异化不在精度(打不过 1mm),在 §6 保真度证书 + §3 重定向 + §5 原生格式 | 鹿明可快速加装质检模块 | 需查:鹿明是否已提供质检证书与重定向 |

> **规格层面能做的到此为止。三条的最终裁决都不在文档里,在真人那里(见 outreach.md)。**

## 9. 本规格最可能死在哪(强制自曝)

1. **证伪条件②翻盘**:力/触觉今天就有买家 → v0 的保守成了错失,竞品带力先发。
2. **证伪条件①致命**:目标客户其实全是 π0 系严格 joint-state → EE-pose 路线整体不适配。
3. **鹿明已内建质检**:则 §6 差异化消失,v0 无相对优势。
4. 三者任一为真,v0 需重估,不是微调。**这就是为什么下一步是问真人,不是画第十版规格。**
