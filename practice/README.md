# practice — 练功场

> 同一套功法,先在反馈最快、代价最低的地方练熟,再往难的领域搬。

## 为什么从这里开始

方法论最初瞄准的是一个审计级报表系统。那是**最难的起点**:

| | 报表系统 | 个人练习 |
|---|---|---|
| 反馈速度 | 周 / 月 | **天** |
| 错的代价 | 要赔钱 | **零** |
| 现实锚在谁手里 | 客户、下游 | **你自己,随时在线** |
| 需要的治理层 | 重(对外/不可逆/PII) | **几乎为零** |

练功要在能立刻看见结果的地方练。先在山里练,再去打妖怪。

## 三个候选领域的判断

**英语练习 —— 最适合,从这里开始。**
反馈是天级的;"什么算说对了"有明确标准;错了没有任何代价。这是这套方法的完美练功场。

**自我精进 —— 太模糊,先定义再开始。**
"什么算精进了"没有定义,所以无法验证,所以练不了。但把它定义清楚,它就变成英语那一类了——
**而"把模糊意图变成可验证标准"这件事,本身就是言出法随最核心的那一步在小尺度上的练习。**

**孩子家庭教育 —— 用 AI 帮忙可以,当试验田不行。**
反馈以**年**计,噪声极大,而且真的不可逆——孩子只成长一次。
它同时满足"不可逆 + 反馈极慢"两个条件,恰恰是最该保守、最不该让 AI 自转迭代的领域。
用 AI 讲概念、出练习、做材料,很好;靠反馈迭代教育决策,不行——等你看到反馈,已经晚了十年。

## 闭环

```
现实出错 → 记一条 → 它永久存在 → 间隔重复直到掌握 → 弱点库 = 内力
```

和 `runtime/` 那套是**同一个形状**,只是去掉了全部治理层(个人练习没有对外动作、
没有不可逆操作、错了不要钱,所以不需要门禁)。

这也是它比"每天背单词"强的地方:**选题不靠想象力。**
你练的永远是现实刚刚打你脸的地方,不是你以为自己弱的地方。

## 用法

```bash
# 记一条(-s 写清是谁/什么打了你脸,这一栏是命门)
python3 practice/practice.py add -d 英语 \
    -w "说了 discuss about" -c "discuss 不加 about" -s "会上被同事复述纠正"

python3 practice/practice.py review          # 今天该练什么
python3 practice/practice.py ok <id>         # 答对了 → 进一档
python3 practice/practice.py no <id>         # 又错了 → 退回第一档
python3 practice/practice.py scale           # 刻度
```

间隔:1 / 3 / 7 / 21 / 60 天,连对五次算掌握。
答错退回第 0 档——**掌握只能靠答对,不能靠时间熬过去。**

## 唯一的判据

> **弱点库在涨 + 攻克率在涨 = 在变强。**
> **弱点库不涨 = 你没在接触会让你出错的难度,原地踏步。**

第二条是这个工具最容易被忽略、也最重要的诊断:如果你连续几周记不下新错题,
不是你变强了,是**你待在舒适区里没有接触现实**。

## 一条纪律

`-s`(来源)留空的条目,刻度会标出来。凭想象补的题,补的永远是你已经想到的地方——
那是原地打转,不是修炼。刻度里"有现实出处"这个百分比,比弱点库的绝对数量更能说明问题。
