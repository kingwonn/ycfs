# 产品定义 v1:给具身大脑卖的那把铲子

> 本文取代 spec-v0 的骑墙部分。**产品定义 = 押注 + 完整价值链**,不是选项罗列。
> 每个押注写明赌的是什么、输了退到哪。验证并行进行,不阻塞设计与打样。

---

## 一、产品是什么(一句话)

> **一套"训练就绪数据系统":手持无本体采集器(硬件级时间同步 + 力/触觉在配)
> + 采集时实时质检 + 交付时重定向与格式引擎 + 可复算的质量证书。
> 卖给大脑厂商的单位不是设备,是「认证有效小时」。**

铲子不是那个夹爪。铲子是**从人的一次演示,到大脑厂商训练管线里一条可信样本**的整条流水线。
硬件只是它的第一环。

## 二、核心押注(三个,全部押明,不许骑墙)

### 押注 1:力/触觉**默认在配**,不是预留
- **赌什么**:12–18 个月内,接触丰富任务(插接/装配/柔性物/食品)成为大脑厂商的军备焦点,
  而这类数据仿真出不了(接触物理是引擎结构盲区 [有据])、纯视觉 UMI 采不了(鹿明产品线无力觉 [据公开信息])。
  **这是全行业唯一一条"仿真与在位者同时够不到"的供给轴。**
- **配置**:每指 F/T(UMI-FT 路线,直接给标量力,≥500Hz)+ 指尖视触觉安装位(DIGIT 路线,BOM $15,v1.1 上)
  + 可锁定夹爪机构(TacUMI 路线,锁定后人的握力退出测量)。
- **输了退到哪**:若 18 个月后力觉仍无生产买家,产品退化为"带硬同步+质检的更好 UMI"仍可卖
  (押注 2/3 独立成立)。力觉模块成本占比控制在 BOM 30% 以内,保证退路不致命。

### 押注 2:硬件级时间同步,目标 P99 ≤ 1ms —— 与消费级方案的代差
- **赌什么**:同步质量是"最适配"的第一硬指标(π0 明确要求硬件触发亚毫秒 [有据];
  行业实测出现过 150ms 抖动 [有据])。GoPro 类方案结构性做不到,**这就是不做 GoPro 方案的理由**。
- **架构**:MCU 作统一时钟主控,硬件触发线直连**全局快门外触发相机模组**(不是消费运动相机)、
  IMU、夹爪编码器、F/T 采样。这是成熟工程,不是科研风险。
- **验收**:每台出厂跑同步自测:LED 闪烁事件在所有传感器流中的时间戳偏差,P99 ≤ 1ms,
  报告写入设备标定档案,随每批数据交付。

### 押注 3:交付双格式——EE-pose 原生 + 重定向合成 joint-space,两类客户都能吃
- **赌什么**:不选边。EE-pose 架构客户直接用原生轨迹;joint-state 架构(π0 系)客户用
  重定向引擎输出的 50Hz 关节轨迹(输入客户 URDF,IK 求解 + 时间重参数化 + 可行性标注)。
- **诚实条款(写进合同)**:重定向输出是合成轨迹,质量随本体而异;证书披露每批的
  IK 可行率与重定向误差分布。**不冒充真机关节数据。**
- **这同时是 32.5% 问题的产品化**:废弃不再发生在客户训练后,发生在我们采集现场
  (实时可行性提示重采)与交付前(标注过滤)。

## 三、数据价值:大脑厂商拿到什么(用他们的货币计价)

| 价值 | 量化 | 对照 |
|---|---|---|
| **有效小时成本更低** | 采集现场拦截废品 → 目标可用率 ≥95% vs 行业 67.5% [有据推算] → 同等预算多 40% 有效样本 | 遥操 $118/h 名义价的真实成本是 $175/有效时 [有据推算] |
| **买不到的模态** | 接触力(≥500Hz)+ 触觉(v1.1),同步于视觉与位姿 | 仿真给不了真实接触;鹿明公开产品线无力觉 |
| **零接入工程** | LeRobot v3 原生 + RLDS 导出,官方 loader 直读;语言标注在内 | 竞品普遍"给转换脚本" |
| **可验收采购** | 质量证书十项指标,公式公开、客户可独立复算 | 行业现状:信卖家话术 |
| **本体适配** | URDF 进,可行性标注出;joint-space 合成轨迹可选 | UMI 生态普遍把 IK 风险留给买家 |

**North-star 验收(整个产品的存在性证明,写死):**
> 一家大脑厂商用本系统数据微调,在**接触丰富任务**上相对其自有基线成功率提升可测(目标 ≥15%),
> 且**续购**。做不到 = 产品不成立,不找借口。

## 四、硬件架构与 BOM 目标

| 模块 | 选型方向 | BOM 目标(小批量) |
|---|---|---|
| 主控/同步 | MCU 时钟主控 + 硬件触发总线 | ¥300 |
| 腕相机 | 全局快门外触发模组,≥720p@60fps,鱼眼 | ¥800 |
| 位姿 | 双目+IMU VIO 模组,后处理图优化 | ¥1,500 |
| 夹爪 | 平行爪+编码器+**可锁定机构** | ¥1,200 |
| 每指 F/T | 2×指部六维/三维力 | ¥2,500(占比最大,力觉押注的成本) |
| 结构/电池/存储 | 1TB 本地,≥4h 续航 | ¥1,000 |
| **合计** | | **≈¥7,300**(目标零售 ¥15–20k,或成本价铺+订阅) |

> 数字是设计目标不是报价;力觉模块 ¥2,500/7,300 ≈ 34%,略超 30% 红线,选型时压到线内。
> 对照:ALOHA 系整套 <$20k [有据],鹿明未公开价。

## 五、商业模式:剃刀与刀片

1. **设备**接近成本价铺(获客,不靠硬件毛利——硬件无定价权是已验证结论 [有据])
2. **软件订阅**:质检引擎 + 重定向引擎 + 证书签发,按台/年
3. **数据服务**:用自家设备网络接采集订单,按认证有效小时计价——设备铺得越多,
   供给网络越大,这是鹿明"百万小时产能"叙事的同一逻辑,但**每小时都带证书与力觉**

## 六、路线图(12 周到第一个存在性证明)

| 里程碑 | 内容 | 机器可查验收 |
|---|---|---|
| M0(8 周) | 样机 1 台:同步总线+腕相机+VIO+锁定夹爪+单指 F/T | 同步自测 P99≤1ms;采 10 条演示全链路出 LeRobot 包,官方 loader 零报错 |
| M1(+4 周) | 质检引擎 v1:实时 tremble/丢帧/静止/可行性提示 | 自采 100 条,现场拦截率与交付可用率 ≥95%;证书自动生成 |
| M2(并行) | 领土验证(不阻塞 M0/M1):outreach 三线发出,收 ≥5 个一线回答 | 押注 1 的市场时钟被真实校准;若一致否定 → 触发押注 1 退路 |
| M3(+4 周) | 第一个 pilot:免费为一家大脑厂商/实验室采一个接触任务小数据集 | North-star 的首次测量(哪怕 n=1) |

## 七、证伪与退路(押注不是赖账)

| 押注 | 证伪信号 | 退路 |
|---|---|---|
| 力/触觉 | 18 个月无生产买家 + pilot 中力觉通道对成功率无贡献 | 摘模块降 BOM 34%,产品仍是"最严同步+质检 UMI" |
| ≤1ms 同步 | 客户实际只要 10ms 级 | 降相机成本档,价格优势扩大 |
| 双格式 | 重定向轨迹被证明训不出可用策略 | 收缩为 EE-pose 专供,靠力觉与证书维持差异化 |
| North-star | pilot 提升不可测 | **产品不成立,全案重估——这条没有退路,它就是最终裁决** |
