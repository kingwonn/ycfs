# 技术路线穷举二:接触力测量(2026-07)

> 研究 agent 带源。**纠正物理错误:手持惯性污染主要是离心项 ω×(ω×r)+欧拉项 α×r,不是科氏力**(刚体工具 v_rel=0,科氏项为零)。

## 第一性:读数分解
```
W_测 = W_接触 − W_重力(R) − W_惯性(a,α,ω)
```
核心不等式:**惯性/重力污染 ∝ 传感器远端质量 m 和惯量 I**。传感器越贴接触点、远端质量越小,污染越小——这条决定所有测量点方案排序。
**握力污染是内力**(不是惯性):传感器在"握力→夹爪闭合"力流路径上时,握力直接叠进读数,算法减不掉,只能靠机构(锁定)或双指求差解耦。

## ⚠ 最关键结论:能测"牛顿级",达不到"计量级"

**分两层:**
- **传感器/换能器层:能达计量级**(商用 6 轴 F/T 出厂溯源 0.5-2% FS;NIST 便携动态力标准 k=2 <0.71% 至 5kHz)
- **系统交付层:手在自由运动下拿不到计量级接触力**。不确定度由补偿残差+结构共振+抓握物惯量未知+时间同步主导。当前最好:静态/慢速经在线辨识 ~0.4N/0.1Nm 残差,IMU+RLS 削非接触分量 >95%,但**绝对接触力残差在零点几到数牛顿,随加速度/冲击恶化**。

> **现实定位:"牛顿级",不是"计量级"。想要计量级必须降速+锁定夹爪去握力+载荷在线辨识,且承认高动态段失准。**

## 最优技术组合(按任务)

- **抓取类**:A2 每指 CoinFT(远端质量≈2g,惯性天然趋零)+ 双指求和/求差解耦握力 + IMU 轻补偿 = **UMI-FT 路线,第一性最干净**
- **工具类**:A1 手柄 F/T(内置 IMU)+ B4 锁定去握力 + B2 载荷辨识去重力惯性 = ForceMimic/TacUMI 路线(实测稳定 ~9N)

一句话:**测量点越贴接触越好(CoinFT指尖)> 手柄F/T;握力用机构去不用算法;重力惯性用IMU+在线辨识去;科氏项对刚性工具可忽略。**

## 剩余未解难题(诚实)

1. 自由手持运动下的计量级接触力——**未解**(补偿残差+结构共振主导,溯源不到<1%)
2. 抓握物惯量未知且每次变——扣不掉,重物快速运动误差显著,**无通用在线解**
3. CoinFT 采样率/带宽公开无;软硅胶+电容天然机械低通,高频接触响应存疑
4. 软传感蠕变/温漂,现场无法重标
5. **跨本体力迁移**:人手软指垫测的力 ≠ 刚性机器人指施加的力,力学 gap 未闭合(呼应 M2-1 最致命风险)
6. 握力污染只在静态锁定相位被解掉,连续变抓持时污染回归
7. 多源(F/T 2000Hz+IMU+位姿)无线手持亚毫秒对齐是工程瓶颈

## ⚠ 对产品定义的重大修正

**押注①的措辞必须改**:"计量级标定力"在手持自由运动下**做不到**——这是物理约束不是工程努力问题。诚实的差异化应改为:**"任务相关的牛顿级力标签 + 锁定相位下的可标定静态力"**,而非泛泛"计量级"。否则规格书写下一个物理上达不到的指标 = 埋雷。这条已入 REALITY。
