# Physical AI · 领域地图(2026-07)

> 配 `learn.py` 用。每一层挑概念,下可证伪的预测,去论文/代码/仿真里验。
> 地图会过期,预测记录不会——**过期的是内容,不是方法**。

## 为什么这个领域适合练这套方法

它自带最硬的现实锚:**物理**。

跑一次仿真,物理不会迁就你的直觉。别的领域你可以嘴硬("我觉得应该这样"),
这个领域不行——机械臂抓不起来就是抓不起来。**一个不会自证的裁判,免费送给你。**

这也是为什么它比"读 LLM 论文"更适合练:LLM 的好坏你得靠 judge 判(可能被污染),
Physical AI 的好坏物理直接判。

---

## 基础层(地基,必须先扎实)

读不懂前沿,九成是这一层有洞。

| 概念 | 值得下的预测方向 |
|---|---|
| **模仿学习 vs 强化学习** | 为什么机器人主流是模仿学习不是 RL?RL 在这里卡在哪? |
| **遥操作与数据采集** | 一条真机数据的成本量级?为什么数据是瓶颈而不是算力? |
| **sim2real gap** | 差距主要来自哪:视觉?动力学?接触力学? |
| **动作表示** | 关节角 / 末端位姿 / 离散 token / 连续分布——各自代价是什么 |
| **接触与操作(manipulation)** | 为什么"抓起来"比"走过去"难得多? |

**起手第一条预测建议**:先预测"数据成本",再去查。这条几乎所有人第一次都会低估一个数量级,
被打脸一次,你对整个领域的判断会立刻校准。

## 中层(方法与架构,主战场)

| 概念 | 2026 现状锚点 |
|---|---|
| **VLA(视觉-语言-动作模型)** | 在 VLM 上接第三种能力:输出物理动作 |
| **action head 的设计** | 离散 token(RT-2 一路)vs flow matching 出连续动作(π0 / GR00T 一路) |
| **世界模型 / 世界基础模型** | 学"世界怎么运转",让机器人先在仿真里学和测 |
| **world-action 模型** | 2026 的合流方向:预训练去想象,微调去行动 |
| **egocentric 人类视频预训练** | 用人的第一视角视频当预训练语料,绕开真机数据瓶颈 |

**2026 最值得知道的一个数**:NVIDIA 报告了机器人灵巧度的**第一条 scaling law**——
人类第一视角数据从 1,000 小时到 20,000 小时,平均任务完成率**翻倍不止**。

这条值得你专门下一个预测:**scaling law 在机器人上成立,意味着什么被证伪了?**
(提示:它挑战了"机器人必须靠真机数据"这个默认前提。)

## 前沿(2026 正在争的)

这一层**预测经常错是正常的**,错了才说明你在真前沿。

- **Cosmos 3**(NVIDIA,2026):把视觉推理 + 世界生成 + 动作预测合进一个架构。
  争点:三合一是真协同,还是三个模型硬拼?
- **GR00T N1.7**(2026-04):3B 参数开源 VLA,Cosmos-Reason2-2B 骨干,
  20,854 小时人类第一视角视频预训练。
- **Gemini Robotics-ER 1.6**(2026-04):空间推理与多视角;与 Boston Dynamics 合作做仪表读数。
- **LingBot-VLA**(蚂蚁):20K 小时真机双臂数据,9 种构型,全开源。
- **公认瓶颈**:不是算力,是**高质量多模态训练数据**。

## 一条学习路线

不要按"读论文列表"走,按**预测被打脸的密度**走:

1. **基础层下 5 条预测**,全部验完。准确率低于 60% 就停在这层别往上。
2. **中层挑 VLA 的 action head 这一条**深挖——它是整个领域设计取舍最集中的地方。
3. **跑一次仿真**。这是这个领域独有的、最便宜的现实锚。你的直觉会在这里被物理直接打。
4. 前沿层随便挑,**预测错就对了**。

## 判据

刻度里只看两件事:

- **前沿常错 + 基础扎实** = 健康,你在真前沿
- **前沿错 + 基础也错** = 别啃前沿了,回去补地基
- **全都对** = 你挑的题太简单,在收集安慰感
