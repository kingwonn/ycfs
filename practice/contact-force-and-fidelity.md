# 两个问题:接触力怎么做 · 数据保真度标准是什么

---

# 第一部分:接触力怎么测

## 一、先把物理写清楚

手持设备上,任何力传感器读到的都不是纯接触力:

```
F_读数 = F_接触 + F_重力 + F_惯性 + F_科氏/离心   (力矩同理)
```

`[有据]` 文献原话:F/T 读数不仅包含真实外部接触力,还包含机器人运动产生的
内部非接触力——重力、惯性力、科氏/离心力及其力矩。

**重力补偿在末端质量与质心已知时可做,但实际中这些参数往往未知,必须在线辨识。**
已有基于牛顿-欧拉的在线可辨识工具动力学模型,连传感器零漂也纳入模型实时辨识 `[有据]`。

### 手持形态还多一个坑

**人的握力会污染测量。** 你用手捏夹爪,捏的力和物体给的反作用力混在一起,
分不开——这是手持相对于机器人本体特有的难题。

## 二、第一性原理:测量点越靠近接触界面,需要补偿的东西越少 `[推]`

| 测量位置 | 补偿负担 | 能给什么 |
|---|---|---|
| **腕部六维 F/T** | 最重:整个夹爪+物体的重力与惯性都要补 | 总力旋量 |
| **每指 F/T** | 中等:只需补指部质量,量小 | 外部接触力 + 内部抓握力,可分离 |
| **指尖视触觉** | **几乎为零**:传感器就在接触界面,自身质量极小 | 力分布、剪切、滑移、纹理 |

> **推论:指尖视触觉是物理上最干净的方案。** 它绕开了整个惯性补偿问题——
> 因为它测的不是"整体受了多少力",是"这一小片接触区被压成了什么形状"。

视触觉原理 `[有据]`:软弹性体后面放一个小相机,弹性体被压时相机逐像素观察其形变,
软件从图像重建接触几何、局部力分布、滑移事件、乃至表面纹理。

## 三、已经有人把路铺好了 —— 两篇可直接参考的实现 `[有据]`

### TacUMI(arXiv 2601.14550)—— 最接近你要做的东西

手持 UMI 形态,加了三样:
- **指尖 ViTac 视触觉传感器**
- **腕部六维力/力矩传感器**
- **高精度 6D 位姿追踪器**

**关键机构创新:可连续锁定的夹爪机构,消除使用者抓握带来的干扰**——
这正好解的是上面那个"人的握力污染测量"的坑。锁定后,能同步采集干净的
接触触觉、力/力矩、夹爪位姿。

### UMI-FT(arXiv 2601.09988)—— 每指力传感路线

便携可扩展的手持设备,配**每指 F/T 传感器**,
**同时捕获外部接触力与内部抓握力**——用传感器位置的选择来分离两者,而不是靠算法。

> **这两篇都是 2026 年初的。说明:①方向被验证 ②窗口还很新 ③你不用从零推物理。**

## 四、供应商与成本 `[有据]`

| 方案 | 代表 | 成本 |
|---|---|---|
| 视触觉(开源) | **DIGIT**(Meta 开源设计) | **BOM 约 $15**;成品由合作方售 **$250–400** |
| 视触觉(商用) | GelSight Mini / Wedge;GelSight × Meta 的 **Digit 360** | 商用价,未查到公开报价 |
| 视触觉(强调可复现) | **GelSlim 4.0** | 开源设计 |
| 其他参考型号 | ReSkin、AnySkin、Soft-Bubble、TacTip | 多为开源 |

市场背景:触觉传感 2026 约 **$142 亿**,2031 预计 $280–300 亿,CAGR 约 15%。

> **成本上最重要的一条:DIGIT 的 BOM 只要 $15。**
> 物料极便宜,贵的是**工程、标定与一致性**——这恰好是单人可以投入、
> 且能形成积累的地方(不是拼供应链和模具)。

**没查到的**:帕西尼(PaXini)、戴盟等中国触觉厂商的产品线与报价,本轮公开检索没拿到。
这块需要单独查——国产供应链的成本可能比 DIGIT 路线更有优势。

## 五、开发路线(由第一性原理排序)`[推]`

1. **先复现 UMI-FT 的每指 F/T**,而不是先上视触觉。
   理由:每指 F/T 直接给标量力,数据结构简单,能最快验证"力数据到底有没有用";
   视触觉给的是图像,还要再训一层解码,不确定性叠加。
2. **机构上抄 TacUMI 的锁定夹爪**——它解的是手持形态的根本污染源,绕不过去。
3. **视触觉作为第二阶段**,等力的价值被验证后再上。DIGIT BOM $15,试错便宜。
4. **标定与一致性从第一台就开始做**——这是前面反复出现的量产生死线,
   而且是唯一无法后补的东西。

# 第二部分:数据保真度标准,到底是什么

上一版我只写了一句"没有共同的尺子",太简略。展开讲。

## 一、用一个类比讲清楚

**你去买一批钢材。** 你拿到的不只是钢——还有一张**材质证明书**:
屈服强度多少 MPa、化学成分百分比、哪家实验室按哪个标准测的。

有了这张纸,你能把钢用在桥上,**不必自己重新做拉伸试验**。

**现在你去买 1000 小时具身数据。你拿到什么?一堆文件。** 你不知道:

- 时间戳抖动是多少毫秒?(行业里实测出现过 **150ms**)
- 位姿误差多少毫米?长时间漂移多少?
- 多少 episode 是废的(缺帧、过短、静止)?
- 同一任务的演示一致不一致?
- 覆盖了多少场景、多少物体?

**所以你只有两条路:自己写脚本验(每个买家重复一遍),或者信卖家说的(自证)。**

> **数据保真度标准 = 给具身数据发一张"材质证明书"。**

同类的东西在别的行业早就有:钢材的材质证明书、食品的营养成分表、
药品的纯度检验、芯片的可靠性报告、信用评级、SGS/BV 的第三方检验。

**具身数据是一个已经在做几十亿订单的市场,却还没有材质证明书。**

## 二、证书上应该印什么(全部可自动计算)

| 指标 | 物理含义 | 怎么算 |
|---|---|---|
| **时间对齐误差** | 各模态时间戳的最大偏差(ms) | 直接统计 |
| **位姿精度与漂移** | 绝对误差(mm)、单 episode 累积漂移 | 回环闭合检测 |
| **抖动 tremble score** | 实际速度轨迹 vs 平滑轨迹的偏差 | 已有公开定义 |
| **完整性** | 缺帧率、缺相机率 | 直接统计 |
| **有效性** | 时长异常比例、静止占比过高的比例 | 分布检测 |
| **一致性** | 同任务轨迹的聚类紧致度 | 轨迹聚类 |
| **多样性** | 场景数、物体数、技能数、光照分布 | 计数 + 熵 |
| **可执行率** | 对给定本体的 IK / 动力学可行比例 | 需客户 URDF |
| **格式合规** | LeRobot / RLDS / OXE schema 校验 | schema check |
| **溯源** | 每条 episode:谁、何时、何地、何设备 | 元数据链 |

**这些全部是可测量的物理量,不是形容词。** 这一点很关键——
"我们的数据质量高"是话术,"时间对齐误差 P99 < 2ms"是规格。

## 三、为什么这是**结构性**空位(不是竞争空档)

这是我认为最重要的一点。三方都需要它,但**三方都没有动力提供它**:

| 谁 | 为什么不做 |
|---|---|
| **采集/数据公司** | 标准会暴露自己的短板。今天他们靠"我们数据好"卖,有了尺子就要被量 |
| **大脑厂商** | 内部有自己的尺子,但**那是竞争优势,不会公开** |
| **本体厂商** | 关注自己本体能不能用,不关心行业统一 |

> **所以这不是"竞争对手还没来得及占",是"每一个在位者都有理由不做"。**
> 这类空位由**激励结构**决定,不会因为竞争加剧而消失——这是它和普通市场机会的本质区别。

而且:**中立性本身就是壁垒。** 一旦第三方标准被行业接受,后来者很难取代——
因为价值来自公信力,公信力来自时间和无利益冲突,不来自技术。

参照物:MLPerf 之于 AI 芯片、穆迪之于债券、SGS 之于货物检验。
**这些机构的护城河都不是技术。**

## 四、四种可能的变现形态(由轻到重)

1. **开源标准 + 开源工具** —— 先建立行业地位,不急变现(MLPerf 路径)
2. **认证服务** —— 收费出具第三方报告,卖家拿去背书
3. **嵌入采集端的 SDK** —— 采集时实时打分,**卖给采集公司**(他们是客户不是对手)
4. **买方尽调工具** —— 卖给大脑厂商,买数据前先验货

**1 → 3 是最自然的路径**:开源标准建立信任,然后把实时质检 SDK 卖给采集公司,
因为他们比谁都想在交付前发现问题(退货成本最高的是他们)。

## 五、和 YCFS 的关系:这就是你那套方法论的产品化

这一点你可能没意识到——**数据保真度标准,几乎就是 YCFS 的三条核心原则做成产品:**

| YCFS 原则 | 在数据标准里的对应 |
|---|---|
| **L0 真值要有出生证**(谁编/何时/被谁接受/错误率) | 数据的溯源链:谁采、何时、何设备、什么标定状态 |
| **被测不能自证** | **卖家自己发的质量报告不算数,必须第三方出具** |
| **门槛只紧不松** | 标准的阈值只能收紧,不能为了让谁通过而放宽 |
| **每个评估自带证伪条件** | 每项指标写明:什么读数说明这批数据不能用 |

**你在 ycfs 里建的那套东西(gate、刻度、阴性对照、自证检测),
换个领域就是这个产品的内核。** 这不是巧合——同一个问题:
**怎么在不能信任生产者的前提下,判断产出是否可信。**

## 下一步该验证什么(按"答案改变架构"排序)

**接触力方向:**
1. 力/触觉数据在实际训练里的权重——是必需项还是研究性加分?(决定 A 值不值得做)
2. 帕西尼/戴盟等国产触觉传感器的产品线与报价(决定成本结构)
3. TacUMI / UMI-FT 有没有开源硬件(决定你从哪一步起跑)

**保真度标准方向:**
4. 有没有人已经在做这件事?(占位检查)
5. 采集公司内部质检做到什么程度?(决定他们会不会买 SDK)
