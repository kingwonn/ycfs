# 独立价值评估:这个 UMI 产品值不值得做

> 作者:监督方(与设计方物理分离)。用途:在设计方的报告到来前,先钉下一个独立判断,
> 到时两相对撞——若设计方报告与本文结论一致,信心增加;若冲突,冲突点就是最该深挖的地方。
> 这是"被测不能自证"用在产品决策上:设计者说"有价值"不算数,要有独立一方的判断做锚。

## 一句话结论

**"纯视觉 UMI 设备"低价值;"UMI + 力/触觉 + 质检内建"有价值潜力,但价值能否兑现,
卡在一个桌面无法回答的事实上——力/触觉数据今天有没有生产模型在消费。
所以此刻正确的动作不是把设计做完,是花一个电话把这个事实问清楚。**

## 价值判断矩阵(不给含糊的"有潜力",给条件)

决定价值的是两个二元事实,四个格子:

| | 力/触觉今天**已有**买家 | 力/触觉今天**还没有**买家 |
|---|---|---|
| **能补上 50Hz/同步鸿沟** | ★ 高价值,现在就做 | ○ 中价值,超前投资,赌 12-18 个月后 |
| **补不上鸿沟** | ○ 中价值,只能卖给做 EE-pose 架构的客户 | ✗ 低价值,两头不靠 |

- 你现在**不知道自己落在哪个格子**。而格子之间的行动截然不同(马上做 / 等 / 转方向 / 放弃)。
- 桌面研究把矩阵画出来了,但**填不了格子**——填格子需要真人回答两个问题。
- 这就是为什么"再写第八份文档"零收益:文档能画矩阵,不能定位你在矩阵的哪一格。

## 我作为独立方,对三条证伪条件的预判(可被推翻)

**① 50Hz joint-state 鸿沟** — 我判断:**可绕,但有代价**。
UMI 给的是 EE(末端)位姿,不是关节角。绕法是交付 EE 轨迹 + 一个"重定向层"让客户映射到自己本体。
但这把 IK 可行性的责任推给了客户,而那正是 32.5% 废弃率的来源。
**净判断:能交付给 EE-pose 架构的客户,交付给严格 joint-state 架构(π0 系)的客户会掉链子。**
这条不证伪 P13,但收窄了"最适配"能触达的客户范围。

**② 力/触觉今天有没有买家** — 我判断:**大概率还没有(生产级),但这恰恰是机会窗口**。
π0/GR00T 的公开输入里都没有力。但"没人吃"有两种解读:
死路(没需求)/ 蓝海(供给不存在所以需求没被激活)。这两种桌面分不清,**只有真人能分**。
我倾向后者,因为仿真做不到接触物理是硬约束,长期一定有人要——但"长期"可能是你耗不起的 18 个月。

**③ 相对鹿明的量化优势** — 我判断:**纯精度维度打不过,差异化只能在鹿明没有的轴上**。
鹿明 FastUMI Pro 报道称 1mm 精度、三产品线、百万小时产能。单人在精度和产能上正面竞争=送死。
唯一可量化优势的轴:**鹿明采视觉+位姿,不采力/触觉**(据现有公开信息)。
如果这条属实,你的差异化不是"更好的 UMI",是"UMI 采不到的那个模态"——回到第①②条。

## 承重结论 + 证伪条件

**承重判断:这个产品在纯视觉形态下不值得做(#3 决定);在带力/触觉形态下值得做的概率,
等于"力/触觉数据在 12 个月内出现生产级买家"的概率——我估 50-70%,但这是我的猜测,不是数据。**

**证伪条件(什么现象证明我错)**:
- 若一个真实大脑厂商工程师说"我们生产模型现在就吃力数据" → 我低估了,应立即全力做,格子跳到 ★
- 若多个从业者说"力数据我们两三年内都不会碰" → 我高估了,该转做纯质检工具或放弃硬件
- 若发现鹿明/某在位者已经在采力/触觉 → 差异化轴消失,整个方向重估

**回退成本**:此刻方向未定、未投产、未开模,回退成本≈这几轮对话的时间。这是最便宜的重估时点。

## 给用户的一句话

设计方的报告会告诉你"这个设备怎么设计"。它答不了"该不该设计"——因为那取决于一个
它和我都没有的事实。**这个产品有没有价值,不由任何一份报告裁决,由第一个愿意跟你说
实话的从业者裁决。** 报告的价值是让你带着一个足够具体的规格去问,而不是空手去问。
