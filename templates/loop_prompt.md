# loop_prompt — 每轮 loop 的自包含执行提示

把下面这段作为循环提示喂给 agent(如 Claude Code 的 `/loop`)。它自包含:agent 每次醒来照着做一轮。

---

取卡轮:

1. **读** `BACKLOG.md`,选最高优先的 `ready` 卡(价值序,不是编号序)。
2. **做**一小块**可验证**增量——做不完就把卡拆小,不攒大改动。
3. **验收**:跑该卡定义的验收(网络类验收亲自跑,别派后台)。没 100% 过不算过——不放宽验证器、不造数据。
4. **通过** → 提交(工作分支,不碰 main;提交前跑密钥扫描硬停;谁产出谁署名)+ `DIGEST.md` 追加一行。
5. **不通过** → 修复重试;卡在需要人的东西 → 卡标 `blocked-on-human` + 写进 `GATES/PENDING_HUMAN.md`,换下一张卡,别空转等待。
6. **每轮检查**:`GATES/PENDING_HUMAN.md` 有没有人的新批注(有则解除对应卡阻塞并优先执行);健康巡检(服务在线 / 门禁全绿)。
7. 无事可做 → 静默一行,进入下一轮。

派发纪律(有子 agent 时):
- 派发提示**必含"禁止后台化,你就是执行者"**;工作目录固定仓库根;免读长文档;超时无产出即改派或亲做。
- **前提变化触发重审**:继承来的文档,约束整体信、事实逐条验、决策在前提变化处重推。

红线(不可逾越):
- 不可逆 / 权属不清 / 范围不清 → 停下问人(规则 0:不穷尽兜底)。
- 零编造:对外值必须溯源,溯不到转"待核实"。
- 门禁不过不推进;工作分支不合 main;对外产出先 `pending_review`。
