# 具身智能 · Physical AI 技术档案

一个自包含的单页记录网站（`index.html`），用于逐份收录播客/文章源材料，并从中持续修订：

1. **源材料库** —— 每份材料编号（S-001、S-002……），记录出处、总结、关键论点、对档案的修订；
2. **技术树发展史** —— 按年代分段的主干时间线，每个节点标注所属技术分支（大脑/小脑/本体/数据/基建/产业）；
3. **产业地图** —— 大脑公司 / 全栈公司 / 平台基建 / 资本政策四类主体，附悬而未决的路线争论。

## 使用方式

直接用浏览器打开 `index.html`。无外部依赖、无构建步骤，深浅色主题自适应。

## 如何新增一份源材料

页面全部内容由 `index.html` 内嵌的 `DATA` 对象驱动：

- 新增材料：在 `DATA.sources` 数组追加一条记录（`id`、`title`、`podcast`、`url`、`date`、`status`、`summary`、`points`、`revisions`）；
- 修订技术树：编辑 `DATA.eras`（年代段）内的 `nodes`（节点）；
- 修订产业地图：编辑 `DATA.industry` 与 `DATA.debates`；
- 每次并入新材料后递增 `DATA.version` 并更新 `DATA.updated`。

## 诚实性约定

- 基线内容（v0.1）由公开资料综合而成，仅作脚手架，以源材料为准逐步替换；
- 有争议的判断进「路线争论」，不写成事实；
- 源材料观点归属讲者，与档案的中立梳理分开陈述。
