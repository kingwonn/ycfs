# 源材料获取方案（Playbook）

目标：把小宇宙等平台上的播客/文章源材料，稳定地转成可归档的文本。分两种环境讨论：**网络开放环境**（本地机器、无出站限制）与**受限环境**（如本仓库当前的远程执行环境，出站流量走白名单代理）。

## 原则

> 能用公开 RSS 就不用网页爬；能用网页静态 JSON 就不用私有 API；需要登录/授权的内容不绕。

不做的事：登录接口、私有 API、绕权限、浏览器自动化硬爬。

---

## 一、网络开放环境：通用获取顺序

1. **RSS / Atom / sitemap** —— 播客本质是 RSS 分发，绝大多数小宇宙节目背后有公开 feed（如晚点聊：`feeds.fireside.fm/latetalk/rss`）。feed 里有标题、日期、show notes、音频直链。
2. **Apple Podcasts / Spotify 反查 feed** —— 用 iTunes Search API（公开、免鉴权）按节目名查 `feedUrl`：
   `https://itunes.apple.com/search?term=晚点聊&media=podcast&country=cn`
3. **页面 HTML 里的结构化数据** —— 小宇宙是 Next.js 服务端渲染，单集页 `<script id="__NEXT_DATA__">` 内嵌完整 JSON（标题、简介、时间轴、音频 URL）；很多站点也有 JSON-LD / OpenGraph 可直接解析。
4. **官方公开 API** —— 仅在有文档、免鉴权时使用。
5. **浏览器渲染抓取** —— 最后手段，只用于前几步全部失效且内容公开的页面。

音频转文字：拿到 feed 里的音频直链后，用 Whisper 类模型本地转写，即可获得全文逐字稿（比任何摘要都可靠）。

## 二、受限环境（本仓库当前环境）实测

出站 HTTPS 走白名单代理，实测：小宇宙、Jina Reader、百度、即刻等一律 `CONNECT 403`（策略拒绝）；`WebFetch` 工具同样被拦（连 example.com 都 403）。**唯一可用的外部信息通道是 WebSearch（服务端搜索）**。在此约束下的有效打法：

### 1. Episode ID 时间戳解码（定位利器）

小宇宙的 episode/podcast ID 是 MongoDB ObjectId，前 4 字节（8 个 hex 字符）是创建时间戳：

```python
import datetime
datetime.datetime.utcfromtimestamp(int("6a13a018", 16))
# -> 2026-05-25 01:04:24 UTC（北京时间 09:04）
```

即使页面完全打不开，也能从 URL 精确得到发布时刻，把「这是哪期节目」变成一个可交叉验证的日期匹配问题。

### 2. 多角度 WebSearch 并行扫描

单一查询命中率低，按角度分工并行搜（本档案用工作流各派一个代理）：

- **精确 ID**：搜完整 episode ID / URL 片段，找公开分享痕迹；
- **候选播客排期**：锁定嘉宾/主题相关的头部播客，反查其单集列表与发布节奏，用日期夹逼；
- **聚合与转录站**：Scripod、Podwise、Metacast、Listen Notes、Apple Podcasts、podtail 等对单集的收录页（常带日期与 show notes）；
- **文字版与转载**：晚点/机构媒体常在节目后 1–3 天发文字版，新浪/网易/36kr/腾讯新闻的转载可被搜索到，是内容还原的最大来源；
- **周边印证**：嘉宾同期的其他访谈、演讲、公司报道，用于交叉校验观点归属。

### 3. 交叉裁决

要求至少两条独立证据链（如：聚合站标注日期 + ObjectId 解码日期 + 更新节奏吻合 + 文字版存在）才确认身份；只有单一来源的信息在档案中标注置信度。

### 4. 本环境定位 S-001 的实例

- `6a13a018` → 2026-05-25 09:04（北京时间）；
- Scripod 标注晚点聊第 166 期发布于 2026-05-25，主题（许华哲再次具身创业）与档案主题吻合；
- 晚点聊更新节奏（165 期 5/20 → 166 期 5/25）吻合；
- 晚点 5/27 发布文字版《对许华哲：具身智能不是机器人学或自动驾驶，是世界上的新物种》；
- 同窗口其他头部播客（张小珺 141/142/143 期）日期逐一排除。

## 三、推荐配置

若希望以后在远程环境直接抓取，可在环境的网络策略里放行这些只读域名：`www.xiaoyuzhoufm.com`、`itunes.apple.com`、`feeds.fireside.fm` 及目标节目的 feed 域。或者在本地环境跑获取步骤（RSS + 转写），把产出的文本材料提交进仓库，远程环境只做归档与综合。
