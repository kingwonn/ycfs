# 分层验证器:L0–L5

「工作是否成立」不是一个布尔值,是一条纵深防线。任何一层都可能放过某类错误,但错误要同时穿过所有层才会到达用户。下面以"每个对外数字都必须可信"的系统为模型展开;换成别的领域(代码正确性、内容合规、Agent 行为),层的职责不变,判据换掉。

## L0 · 真值编译

把权威来源(人工基线、规范、标注)编译成一个断言集。每条断言 = (输入, 期望输出, 溯源)。

**关键不是"有断言",是"真值有出生证":** 谁编的、何时编的、被谁接受过、错误率多少。一个反例:如果你的"人工基线"其实是旧系统某次自动跑出来的回归输出,那你的整栈最强结论只是"新系统复刻了旧系统某次输出",不是"数字对"。专家标注集本身有约 6% 错误率——你的断言集守护的可能有一部分是噪声。**先给真值上出生证,再谈守护它。**

## L1 · 出口零编造(运行时,每次请求)

每个对外的关键值,在离开系统前必须能溯源回真源。溯不到 → 硬阻断(返回明确错误 + 未溯源项),绝不放行一个"看起来对"的值。

- 中英/多语种**等强**:护栏不能只在一种语言下生效。
- 用 property-based 随机对抗持续验证护栏本身:N 条随机篡改必须全被拦 + N 条真值必须零误伤。
- 数字域与语义域分离:数字走确定性校验,语义走 L5;**LLM 永远拿不到数字的最终裁决权。**

## L2 · 发布前门禁(每次发布)

一条命令跑全部单元验收 = N 条"腿"。任一腿红 → 退出非零 → 不许发布。

- **门槛只紧不松**:每条腿的阈值只能往严改。"为了过而调低阈值"就是自欺,把这条写进纪律。
- **分层促升**:改动运行时代码,先上传预览版本(不接生产流量)→ 对预览跑线上三检(抽样 / 探针 / 完整性)→ 全绿才促升 100%。
- **门禁自己跑门禁**:促升器不信调用方传来的"已通过",自己重跑一遍 gate。(真实事故:某次管道吞掉了 gate 的退出码,红灯版本被促升——此后促升器自跑 gate,结构性封死。)

## L3 · 持续在线(每天)

发布前全绿 ≠ 生产一直对。夜检探针定时对生产抽样(核心断言滚动覆盖 / 关键旅程 / 重放确定性),结果落一面"红绿墙"。

- 免费额度下用滚动抽样(每晚一批,数晚覆盖全量)。
- **缺勤要告警**:探针靠定时器,定时器停了要有人知道,否则"一直绿"其实是"根本没跑"。

## L4 · 覆盖增长

验证器的覆盖面要能自增长,但不能自我论证。管道:出题引擎生成候选 → **人审判题目质量** → 机器 0 容差比对判数字对错 → 双门都过才晋级进断言集。

**防自我论证的铁律:不存在"候选 → 真值"的自动边。**
- 出题模型 ≠ 被测模型(否则模型给自己出容易的题)。
- 晋级的真值锚**不能是被测系统自己的输出**——必须锚定独立来源(原始凭证 / 独立真值),否则被测今天的静默 bug 会被晋级成明天的"真值",永久以 0 容差守护一个错误。

## L5 · 语义裁决

数字全对,但"答非所问 / 空洞话术 / 张冠李戴"——这类 L0-L4 抓不到,需要一个裁判。用 LLM-as-judge,但严守四条:

1. **异模**:裁判模型 ≠ 出题模型 ≠ 被测模型;裁判服务与被测**物理分离**(裁判不住在被告家里)。
2. **rubric 明文且服务端固定**:裁判只按公开准则打分,客户端无权改模型、改准则。
3. **保守偏置**:裁判只能把绿改红,永不能把红改绿;错杀可人工申诉,漏放不可接受。
4. **可复现 + 校准入账**:温度归零(同一输入反复裁不许翻案);judge 与真人的一致率进时间序列,一致率跌破阈值 → 裁判停用。

**一个诚实的陷阱**:如果"judge-人一致率"是 AI 在自己改过三轮的准则上给自己打的分,那它测量的是"准则对建造者偏好的拟合度",不是语义质量。真校准需要真人盲标(不看 judge 结论、不看 rubric,独立判)。在拿到真人基线前,这个一致率数字不该进对外话术。

---

## 贯穿全层的两条铁律

- **门槛只紧不松。** 放宽验证器 = 自欺。
- **被测不能自证。** 真值锚、裁判身份、人核环节,任何一个落到被测系统自己身上,自证通道就打开,污染开始复利。

## 一张自检清单

- [ ] 我的真值有出生证吗?(谁 / 何时 / 被谁接受 / 错误率)
- [ ] 每个对外值都能溯源吗?溯不到会硬阻断还是"看起来对"就放行?
- [ ] gate 的每条腿阈值,历史上只紧过没松过吗?
- [ ] 促升器信不信调用方的"已通过"?
- [ ] 夜检停了我会知道吗?
- [ ] 晋级的真值锚,是不是被测系统自己?
- [ ] 裁判和被测,是同一个模型吗?
- [ ] 那个"一致率"数字,有过一次真人盲标吗?
